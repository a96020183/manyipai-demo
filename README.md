# 慢一拍：班群風暴｜試玩版

> 截圖是真的。接下來發生的事，也是。

第 11 屆 Design For Taiwan「Impact Now!」社會創新挑戰賽參賽作品《慢一拍：班群風暴》的數位端試玩版。

**線上試玩：** https://a96020183.github.io/manyipai-demo/

**規格說明（組員必讀）：** https://a96020183.github.io/manyipai-demo/spec.html

## 三種玩法

- **🎲 桌遊模式**：4–6 人圍著桌子，這台裝置放在中間當「班群」（正式版玩法；2–3 人可練習，會補電腦同學）。
- **🙂 單人體驗**：一個人和 3 位電腦同學同桌，約 10 分鐘。
- **▶ 展示版**：示範玩家自動玩完整局，附解說字幕，不用操作（網址加 `?show` 可直接播放）。

## 說明

- 單一 HTML 檔，不需安裝、不需網路以外的任何服務。
- 遊戲紀錄只存在玩家自己的瀏覽器（localStorage），不會上傳到任何地方。
- 所有人物與事件皆為虛構。內容涉及校園網路霸凌情境；如需協助：安心專線 1925、教育部反霸凌專線 0800-200-885。
